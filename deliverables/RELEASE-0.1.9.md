# 0.1.9 跑道操作界面与实时对线

[下载 APK](track-timer-0.1.9-field.apk)。两台安卓都直接覆盖安装，保留旧录像与成绩，不要先卸载。

## 这版怎么用

1. 两台手机连接同一 Wi-Fi 或热点。起点选择“起点发令”，点“开启起点服务”。
2. 终点选择“终点录像计时”，填写起点地址、六位配对码。首次跑道测试建议选120帧并保留实时预览。
3. 点“连接、对时并开始录像”。画面就绪后，**实时预览已有红线**。将手机固定在终点线延长线上并调平，让实际终点线靠近起点的一侧与红线重合；可左右拖动红线微调。
4. 对线后点 **“对线完成，允许发令”**。红线锁定，机位保持不动；起点显示就绪后再发令。
5. 所有运动员过线后，终点点底部“停止录像并判线”。保存及对时复核结束后，进入逐帧页面。
6. 红线会带入判线页。用滑块和±1/±10帧按钮，找躯干第一次到线的画面；上下滑动找到运动员/道次输入框，填写后保存。多人可分别选择画面，遮挡时可同帧保存并列。

为了复用已经在这台手机验证过的高速录像会话，对线阶段已在录像，会显示已录时长。**3分钟上限包含对线和等待时间**；超时需新开一场。手动停止仍需至少录满6秒。

## 界面变化

- 首页分为起点、终点、历史场次；设备测试和日志导出放进“设备与日志”。
- 实时预览增加红线，位置随场次保存，也会记住上次位置。发令必须同时满足相机出帧和终点操作员确认。
- 起点发令、终点确认/停止、逐帧及保存按钮固定在底部；统一按钮、卡片、字体和状态提示。
- 继续保留已修复的画面比例、方向、逐帧显示与高速时钟校验。精确模式不自动降档。

## 第一次跑道实测

先做一次短距离120帧测试，确认红线与真实终点线一致、起点提示音可听、终点正常保存和逐帧判线。手机固定后不要移动；多人过线须完整留在画面里。

两端都可从首页“设备与日志”进入“仅导出日志 ZIP（小文件）”。若需要排查，请一起发回两端日志。240帧需要另行验证本机带预览的稳定性。

成绩以起点电子事件为零点，声音输出延迟和整套物理计时精度仍未标定。本次为跑道实测版，软件检查不能代替两台手机的现场验证。
