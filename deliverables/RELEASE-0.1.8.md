# 0.1.8 画面放大与高速批次校准

[下载APK](track-timer-0.1.8-field.apk)。可直接覆盖旧版，保留录像和日志，不要先卸载。两台手机建议一起升级。

## 本次变化

- 终点预览和逐帧判线画面按视频原比例撑满页面宽度，竖幅画面明显变大。页面可上下滚动，连接、停止录像、逐帧和保存按钮仍在原来的顺序中。
- 判线画面上下滑动可滚动页面；左右拖动或轻点画面可定位红线。
- 保留0.1.7已由用户确认正常的方向、比例和逐帧显示处理。
- 修复带预览的120/240帧高速校准：Android会把一个高速批次展开为多条回调，共用帧编号，其中部分时间戳按名义帧率推算。新版先核验完整批次，再用每批末尾原始时间戳与编码帧直接对齐。
- 批次不完整、展开规则异常、真实时钟不匹配、录像不足5秒等仍会拦截。匹配容差仍为2微秒，没有用增大容差、拟合偏移或MP4播放时间来生成成绩。
- 符合该批次模式的旧场次会在打开时重新检查，原始相机JSON和录像不改写。未通过其他检查的场次仍可能只供查看或复核。

## 建议检查

1. 升级后先打开11:41那场历史录像，检查能否显示时间，向后选到发令后的画面，再填写运动员并保存。这一步可直接用手机里保留的旧录像。
2. 检查预览和逐帧画面是否足够大；在画面上向上滑动可找到下方按钮，左右拖动红线对准终点。
3. 再按[双机跑道操作](RELEASE-0.1.6.md)录一次120帧短测试：等终点就绪后起点发令，终点至少录满6秒、所有人过线后停止。
4. 把终点“仅导出日志 ZIP（小文件）”发回。240帧带预览本次有模拟回归测试，尚无这台手机的新现场日志，建议先验证120帧。

本次使用已上传日志做了离线重算；不等于新版已在手机上实跑。成绩仍以电子发令为零点，声音输出延迟和整套物理精度未经标定。
