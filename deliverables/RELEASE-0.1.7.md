# 0.1.7 预览与录像查看修复

[下载APK](track-timer-0.1.7-field.apk)。两台安卓建议都覆盖升级，保留旧录像与日志，无需卸载。起点Android8+，终点和逐帧查看Android9+。

## 修复内容

- 预览不再重复施加传感器旋转；按正确的画面比例居中显示，并随视图尺寸更新。等比例显示可能留边，避免把画面拉伸来填满。
- 计时检查失败时，仍尝试打开已保存录像，支持滑块和逐帧前后查看。此前“相机与本机时钟未通过检查”会直接跳过画面加载，形成黑框。
- 不能信任计时数据时明确显示“计时不可用”，继续禁止保存成绩。没有放宽时钟或帧索引校验，也没有用播放时间、名义帧率替代采集时间。
- 新报告记录具体失败项；旧报告按已有字段解释，缺少证据时明确提示。当前这一次时钟校验为何失败，仍需这次终点日志确认。

## 这次先这样检查

1. 升级后先打开“历史场次与判线”，选刚才黑屏的那场。检查画面能否出现，以及±1帧能否正常切换；这一步不需要重录。
2. 如果仍提示计时不可用，先在首页选择“仅导出日志 ZIP（小文件）”，把终点日志发回，保留原录像。
3. 再做一段120帧短录，观察物体方向和比例是否自然。手机保持竖直、固定机位；画面周围留边属于等比例显示。
4. 双机发令流程继续按[0.1.6操作说明](RELEASE-0.1.6.md)。声音延迟和整套物理精度仍未校准。

本版软件回归测试不代表已在该手机上验证正确。若录像文件本身无法解码、系统不给逐帧数量，仍会显示明确错误；日志能进一步区分这些情况。
