# 0.1.3-probe · 自动采集隔离诊断版

[下载 APK](track-timer-0.1.3-probe.apk)。用于查明“请求60帧、实际30帧”发生在哪条输出通道，尚不代表60帧已修复。

## 操作

1. 覆盖安装旧版，不卸载。打开后确认页首显示 **0.1.3-probe**。
2. 固定手机、保持光线充足，点击 **“一键排查60帧（约1分钟）”**，允许相机权限。
3. 保持 App 在前台直到自动排查完成。全过程不显示预览，这是预期行为。不要切换应用、锁屏或另外进行声音/对时测试。
4. 点击 **“仅导出日志 ZIP（小文件）”**，发送这个 ZIP。无论实际30/60/120帧或出现错误，都保留结果。

程序自动用同一后置相机依次运行：720p纯采集、720p仅录像、1080p纯采集、1080p仅录像、720p120帧高速仅录像。每项测量10秒，不支持或失败会写入日志并继续；可随时停止，切到后台也会中断后续项目。

“纯采集”使用 PRIVATE ImageReader，只记相机帧时间戳、立即释放图像；不显示预览、不读取像素、不启用编码器、不保存视频。“仅录像”使用 MediaRecorder 并保存 MP4。报告包含同次运行ID、传感器与消费端实际帧率、温度/省电状态、相机实际配置和分辨率能力。

## 结果边界

纯采集达到60帧不代表录像也达标。不同消费者可能使相机选择不同管线，差异只能缩小排查范围，不能单凭它断言编码器故障。自动汇总要求至少5秒有效测量，传感器与消费端均达到请求帧率的90%；错误、缺失或过短记录不计为达标。120帧测试使用专用高速会话；仍需核实批量元数据和视频时间映射。

软件自动化检查、签名和真机待验证事项见 [验证记录](../track-timer/verification/VALIDATION-0.1.3.md)。声音功能与检测阈值未改，本版仍不生成跑步成绩。
