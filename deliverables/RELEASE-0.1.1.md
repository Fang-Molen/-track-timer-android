# 0.1.1-probe · vivo 复测版

本版针对“没有发令音、请求60fps但实际30fps”的真机反馈改进播放配置和相机诊断。

- 短音改走媒体通道，音量键控制同一个通道；记录焦点、音量/静音、播放进度和实际输出设备，不自动改变系统音量。
- 新增「只试听发令音（不录音）」，用于区分播放和录音同时运行的问题。
- Android9及以上在相机会话创建时提前提交帧率，并检查预览与录像两类输出的帧时长；保留Android8兼容路径。
- 相机报告增加实际AE范围、帧时长和控制模式；采集或保存视频任一达不到请求帧率时明确提示，缺少编码帧率测量也不判为通过。
- 报告内版本与APK保持一致，录音异常保留已采集的部分数据。

## 安装和复测

下载本目录 track-timer-0.1.1-probe.apk，覆盖安装旧版。签名相同，无需卸载，旧报告继续保留。

1. 打开后确认页首显示0.1.1-probe，先点「只试听发令音（不录音）」。
2. 再点「测试发令音与麦克风」，记录两种方式是否都能听到“滴”声。
3. 固定手机录制10秒，记下采集帧率与编码视频帧率。
4. 导出新的诊断ZIP；即使仍无声或30fps也请保留，新字段可以进一步定位。
