# 0.1.2-probe · 相机兼容测试版

本机自带相机能拍60帧，本版寻找App能够实际调用的录像配置。新增1080p60、关闭预览的60fps录像，以及设备明确支持时的实验性120fps高速入口；每个模式独立保存真实采集/编码帧率，不将请求值当作成功。

## 安装和操作

下载同目录track-timer-0.1.2-probe.apk，覆盖安装旧版，无需卸载。页首应显示0.1.2-probe。

1. 先用默认“1080p · 请求60帧 · 含预览”录制10秒。
2. 若仍约30fps，切换“720p · 请求60帧 · 仅录像”，再测“1080p · 请求60帧 · 仅录像”。无预览是该模式的正常行为，视频仍会保存。
3. “720p · 请求60帧 · 含预览（对照）”用于比较旧配置。普通模式仍未达到目标时，再试“720p · 请求120帧 · 高速实验”；不支持会明确提示，不能保证所有设备都能运行。
4. 完成后点 **“仅导出日志 ZIP（小文件）”**，把这个ZIP发来。原始视频/录音继续保存在手机里，需要时可完整导出。

界面列出各模式最近一次结果。只需看实际采集/视频帧率；高速模式的预览可能只有30fps。遇到启动失败或未达到目标也保存日志。明确选定的模式不会偷偷退成30fps；自动模式另保留旧版60/30选择行为。

软件检查：53项自动测试通过，APK构建与lint通过（0错误、3项原有提示），v2签名与0.1.1相同。尚无用户手机对新版的真机报告，不能把软件检查作为60fps或0.05秒计时精度证明。声音检测阈值本次没有改动。
