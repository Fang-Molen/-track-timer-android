在 GitHub 文件页面点击 Download / 下载按钮。如仓库设为私有，需要登录已授权的 GitHub 账号。

APK 用于 Android 8.0 及以上手机；可在 iPad 下载后传到安卓手机安装。两台安卓使用同一个 APK。0.1.1 与旧版签名相同，可直接覆盖安装，保留已保存的报告；无需卸载。

当前为设备验证版，可试听、测试设备/双机校准/录像/录音并导出报告；尚不生成训练成绩，真机精度仍待验证。
