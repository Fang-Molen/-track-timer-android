安装后点“一键排查60帧（约2分钟）”，完成后导出小日志。自动比较默认/录像用途和自动/手动曝光，全程无预览。能否解决普通60fps仍待本次真机验证，田径计时精度尚未验证，当前尚不生成跑步成绩。
