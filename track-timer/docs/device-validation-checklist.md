# 真机验证检查表

请每台手机分别执行，再做双机测试。记录机型、系统版本、App 版本和问题出现的步骤；导出 ZIP 提供原始证据。

- [ ] 首次启动无崩溃，文字、输入框和按钮可操作；拒绝权限后可再次授权。
- [ ] 设备报告成功保存；请求帧率和实际录像帧率分别显示。
- [ ] 日光下固定录像 10 秒，MP4 可播放，采集和编码帧率接近请求值；记录最大帧间隔。
- [ ] 低光与连续多次测试时，没有把降帧显示为稳定 60 fps。
- [ ] 麦克风测试可听到一次短音，WAV 可播放；硬件时间戳样本数大于零时才有时间映射候选。
- [ ] 静音或没有检测到测试音时，显示缺少候选；不得出现伪造的准确发令结果。
- [ ] 授权后同时录像与录音，完整保存两类报告。
- [ ] 在采集时切到后台、返回，界面可恢复，麦克风/相机已释放；中断报告不被标为完成录像。
- [ ] 两机同网靠近，正确地址/配对码可校准；错误码、断网与关闭起点服务有明确失败提示。
- [ ] 同一会话多次校准，保存所有交换样本；会话重启后不沿用旧漂移估计。
- [ ] 将手机按 30/60/100/200/400 米现场布置检查网络覆盖；失败只是连接结果，不能作为计时精度结论。
- [ ] 完成测试后导出 ZIP，确认每个完成视频/音频都有对应 JSON。导出文件可解压。

这张表用于验证采集与操作功能。精度验收另需共享事件源和独立可靠参考；随后对同一次发令跑报告有符号偏差、绝对误差分布、最大误差、失败比例及遮挡并列比例。
