# Field UI 0.1.9

User wants a coherent near-product interface and a red finish reference in live preview so the phone can be aligned before a track trial. 0.1.8's two real trials already passed camera/sync calibration and saved results. Preserve that working capture/timing path.

Approach: reuse the continuous high-speed recording session, show its preview with the reference immediately, and require an explicit alignment confirmation before publishing READY. This meets the user's allowance for alignment after recording starts and avoids a new standby-camera/session transition. Explain that alignment time is already recorded and included in the180s limit. A separate pre-record camera session was rejected for this iteration because it would add unverified high-speed surface transitions. Use native Android views, no new dependency or permissions.

- New clean launcher HomeActivity: role cards, history, secondary device/log tools. MainActivity remains the existing diagnostic screen.
- Shared visual style: pale background, dark ink, teal primary buttons, restrained cards, clear stage/status text, large touch targets. Header/body/footer shell keeps primary recording controls outside scrolling content.
- Finish: connection form, real camera preview with red line, alignment instructions, explicit “对线完成，允许发令”, then waiting/running status. Ready cannot be published before the encoder has frames and user confirms. Line locks after confirmation; reset confirmation for every new trial. Cancelling/background revokes readiness. Stop stays reachable. Hide connection form during recording without hiding/reparenting TextureView.
- Persist a normalized image-space line fraction in preferences and the race journal; carry it into review. Letterboxing must not change its meaning. Default0.5 for old recordings. Preview with two surfaces keeps the existing validated CameraPreviewTransform and batch pipeline.
- Review: same image-space line, clear frame/time information, persistent step buttons and save action, athlete field and readable history labels. Vertical swipes scroll; horizontal gestures move line. Keep exact-index decoding and all clock/identity/count gates.
- Starter: readable pairing card and state, prominent fixed fire action; retain readiness, sound/cue and cancellation checks.
- Version0.1.9-field/code10, existing package and certificate. Deliver to the existing repository only; preserve root README, old releases and user data. No claim that redesign verifies optical/acoustic accuracy.

Acceptance: tests for live overlay, saved/reference restoration, image-space positioning across aspect ratios, alignment-before-READY and cancellation; existing timing/camera/permission regressions; emulator visual/touch review if available; full tests/build/lint, independent final review, signed APK and remote byte verification.
