# 0.1.3 自动采集隔离诊断

用户已明确同意按“去掉预览与编码、测相机原始帧，再对照录像”的思路交付 APK，由用户上真机运行。当前不宣称已修复 60 FPS。

新增 PRIVATE ImageReader 纯采集模式，720p/1080p、请求固定 60 FPS。只读时间戳并立即关闭图像，不读像素、不创建预览、MediaRecorder 或视频文件。使用独立消费线程和有界记录，保存传感器及消费端时间戳、消费延迟、错误和声明的最短帧周期。没有对应公开能力时明确报不支持，不换分辨率/帧率/格式。

一键自动对照：720p纯采集 → 720p仅录像 → 1080p纯采集 → 1080p仅录像 → 720p120帧高速仅录像。每步10秒；同次运行固定同一个后置相机；失败写入报告继续；用户停止或离开前台后不再推进。每步无预览，运行时禁用音频、对时、手动录像和导出。保存运行ID关联的每步报告与汇总，导出沿用小日志ZIP。若没有支持的模式也必须恢复界面。

比较以至少5秒有效时间戳为依据，并要求传感器与对应消费端共同达到请求帧率的90%；错误、缺失、取消、短片段均不能算达标。纯采集达标不等于录像达标；不同Surface消费者可能触发不同相机管线，差异只能指向输出通道/编码相关分支，不能单凭它认定编码器故障或厂商白名单。高速采集结果不证明计时精度或批量元数据映射。

设备报告补充PRIVATE输出能力、公开流用途、手动控制范围、支持能力及电量/省电/温度状态；逐帧补充3A、防抖、降噪等实际配置。仅诊断，不写未知厂商私有参数。
