# 0.1 设备验证版交付记录

日期：2026-11-01（北京时间）

## 已完成

- 原生 Android APK：设备能力报告、双机校准、短视频/相机时间戳、测试音/麦克风时间戳、ZIP 导出。
- 核心 23 项 JUnit 测试：偏移及不确定范围、异常/矛盾时间戳、漂移会话隔离、实际帧率与帧间隙、合成声音检测、真实 TCP 配对/超时/关闭、延迟资源回调的释放。
- 4 项 Robolectric Android 框架测试：界面启动、相机权限拒绝、前后台服务释放、校准中断后控件恢复。合计 27 项测试通过；这些测试不代替物理相机和麦克风验证。
- 构建与静态检查命令：`:core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`。
- APK 签名检查：Android v2 签名有效，调试证书；包名 `cn.tracktimer.app`，版本 `0.1.0-probe`，最低 Android 8.0/API 26，目标 API 35。

## 独立审查与修正

独立审查发现三项重要问题，已完成修正及回归验证：

1. 较慢但矛盾的时钟交换样本可能被筛选丢掉：全部已接受样本先做一致性检查，再选择低延迟样本估计。
2. 逐字节慢速请求可长期占用校准连接：现在整条请求具有绝对截止时间，并保留字节数限制及取消检查。
3. 退出时相机尚未打开，回调可能被销毁：设备状态回调留在主线程，由可取消的资源门管理迟到的相机对象；停止时仅移除本 App 的自动停止任务。

同时处理了已取消且尚未执行的校准任务不进入 finally 的情况：离开前台时重置操作状态，并忽略旧任务的迟到界面回调。

Android 框架启动测试另发现 TextureView 禁止设置背景 drawable，会导致页面创建失败；已将背景保留在外层容器，启动及权限测试转为通过。

## 范围与选择

- 本次交付设计阶段 A；不生成运动员成绩。阶段 B/C 需要真机结果后继续实现。
- 中文、竖屏、Android 8.0 及以上；横屏/平板优化和多语言不在本次范围。
- 核心接口相互依赖，测试先建立后合并实现；网络测试使用实际本地 TCP，不把模拟数据结果当作手机精度证据。
- 源码保留在独立的 `feat/device-validation` 分支；没有推送、发布商店或修改其他项目。

## 已知限制与待完成验证

- 未连接用户的真实手机。60 fps 稳定性、声学时间偏差、相机采集时间与编码视频 PTS 的对应关系尚未标定。
- 0.05 秒是未来训练版的验证目标，本版没有宣称达到这一精度。
- 录音被正常取消时保留已采集数据；若硬件在读取期间抛出异常，目前可能只保存错误报告，异常前的部分 PCM/时间戳保留尚待完善。
- 静态检查保留竖屏适配及可回收缓存空间使用建议；不影响 APK 构建。低存储时采用保守拒绝录像的行为。
- 尝试启动 API 35 软件模拟器并连接调试通道，但在验证窗口内 package 系统服务未就绪，未进行 APK 安装运行。改用 API 28 的 Android 框架测试完成界面/权限/生命周期检查；API 35 整机模拟器运行和真实硬件测试仍待完成。真机请按 `docs/device-validation-checklist.md` 执行。
